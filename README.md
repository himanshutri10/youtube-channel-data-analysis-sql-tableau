
# YouTube API Data Analytics Project

## Project Overview

This project explores insights from YouTube channel data using the **YouTube Data API**.
It focuses on understanding how different video attributes impact engagement metrics like views, likes, and comments.


## Analysis Ideas

1. Views per video
2. Likes and comments vs. views
3. Title length vs. views
4. Video duration analysis
5. Upload schedule patterns


## Key Learnings

Through this project, I (Himanshu Tripathi – Product Manager) gained hands-on experience with:

* YouTube Data API integration and Python API handling
* Creating and interpreting various analytical charts
* Performing **Exploratory Data Analysis (EDA)**
* **Data preprocessing** and cleaning techniques
* **Word Cloud** generation for video titles
* Real-world analysis of top YouTubers and my own YouTube channel
